# Running Tests and Results Output

## Running Tests

| I need to... | Path |
|---|---|
| Run a k6 test script | `using-k6 run-k6-test-script` |
| Run distributed tests (k6-operator, Kubernetes) | `testing-guides running-distributed-tests` |
| Run large-scale tests | `testing-guides running-large-tests` |
| Automated performance testing (CI/CD) | `testing-guides automated-performance-testing` |
| Calculate concurrent users | `testing-guides calculate-concurrent-users` |
| Synthetic monitoring | `testing-guides synthetic-monitoring` |

## Results Output

| I need to... | Path |
|---|---|
| End-of-test summary (default output) | `results-output end-of-test` |
| Custom summary (`handleSummary()`) | `results-output end-of-test custom-summary` |
| All real-time output backends | `results-output real-time` |
| Built-in web dashboard | `results-output web-dashboard` |
| Grafana dashboards | `results-output grafana-dashboards` |
