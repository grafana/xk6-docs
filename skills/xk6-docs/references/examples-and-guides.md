# Examples and Testing Guides

## Find Example Scripts

`--depth 1 examples` — lists all available examples. Common ones:

| What | Lookup path |
|---|---|
| Basic HTTP GET | `examples single-request` |
| REST CRUD operations | `examples api-crud-operations` |
| HTTP authentication | `examples http-authentication` |
| OAuth authentication | `examples oauth-authentication` |
| WebSockets | `examples websockets` |
| File uploads | `examples data-uploads` |
| Data parameterization | `examples data-parameterization` |
| Functional testing | `examples functional-testing` |
| HTML forms | `examples html-forms` |
| Correlation and dynamic data | `examples correlation-and-dynamic-data` |

## Choose a Test Type

`testing-guides test-types` — overview of all types. Drill into specifics:

| Type | Lookup path | When to use |
|---|---|---|
| Smoke | `testing-guides test-types smoke-testing` | Verify scripts work, minimal load |
| Load (average-load) | `testing-guides test-types load-testing` | Expected normal traffic |
| Stress | `testing-guides test-types stress-testing` | Beyond normal, find limits |
| Soak | `testing-guides test-types soak-testing` | Long duration, find leaks |
| Spike | `testing-guides test-types spike-testing` | Sudden traffic bursts |
| Breakpoint | `testing-guides test-types breakpoint-testing` | Find absolute max capacity |

For results output and backends, see [running-and-output.md](running-and-output.md).
