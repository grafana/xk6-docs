# jslib

Community libraries imported via URL (e.g. `import { ... } from 'https://jslib.k6.io/...'`).

| I need to... | Path |
|---|---|
| All jslib libraries | `javascript-api jslib` |
| httpx (session wrapper with base URL, headers) | `javascript-api jslib httpx` |
| k6chaijs (BDD assertions: expect/describe) | `javascript-api jslib k6chaijs` |
| testing (Playwright-inspired assertions) | `javascript-api jslib testing` |
| utils (randomString, randomIntBetween, etc.) | `javascript-api jslib utils` |
| AWS services (S3, SQS, Lambda, etc.) | `javascript-api jslib aws` |
| TOTP generation | `javascript-api jslib totp` |
| HTTP instrumentation for Pyroscope | `javascript-api jslib http-instrumentation-pyroscope` |
| HTTP instrumentation for Tempo | `javascript-api jslib http-instrumentation-tempo` |
